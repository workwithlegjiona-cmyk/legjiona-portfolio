# Legjiona Gjergji — Portfolio Universe

Portofol 3D interaktiv (Three.js): Dielli → profili → galaksia me planetët si kategori.

- `index.html` — e gjithë faqja (HTML/CSS/JS, pa build)
- `assets/` — fotot, logot, certifikatat
- `serve.js` — server lokal për provë: `node serve.js` → http://localhost:5178

Deploy: Vercel (static, pa konfigurim).
